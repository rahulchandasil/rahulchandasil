## 🛒 NextCart AI – AI-Powered E-Commerce Platform

A production-ready AI-powered e-commerce platform built using the MERN Stack. The application provides a complete online shopping experience with AI-powered product recommendations, secure authentication, payment integration, and a comprehensive admin dashboard.

### ✨ Key Features

- 🤖 AI Shopping Assistant & Smart Product Recommendations
- 🔐 JWT Authentication & Google OAuth
- 🛍️ Shopping Cart & Wishlist
- 💳 Razorpay Payment Gateway
- 📦 Order Management
- 👨‍💼 Admin Dashboard with Sales Analytics
- 🖼️ ImageKit Integration
- 📧 Email Verification & Password Reset
- 📱 Fully Responsive UI

### 🛠️ Tech Stack

**Frontend:** React.js, Redux Toolkit, Tailwind CSS, Vite

**Backend:** Node.js, Express.js, MongoDB, JWT, Mongoose

**Services:** Razorpay, ImageKit, OpenRouter AI
